What's New

          ✎
          
            Edit stops after uploading
            Every stop now has an edit button. Click it to change the stop number or set
            TAIL / NOSE, then press Enter to save — the list re-sorts itself.
          
        
    • 
        
  • 
          🔗
          
            Same address? Combine the stops
            When two or more stops go to the same company and city, you'll be asked whether
            to merge them. Merged stops print as one card listing every order number, and
            the remaining stops can be renumbered automatically.
          
        
    • 
        
  • 
          ✓
          
            Print check on uploaded lists
            Uploaded lists now get the same warning as manual entry if TAIL or NOSE is on the
            wrong stop, or if you've used the same stop number twice.
